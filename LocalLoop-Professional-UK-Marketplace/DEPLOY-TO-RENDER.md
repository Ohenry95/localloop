# Deploy LocalLoop to Render (beginner guide)

1. Sign in to GitHub and create/open the `localloop` repository.
2. Upload the **contents** of this folder to the repository root (not the ZIP file). Make sure `app.py`, `requirements.txt`, `render.yaml`, `templates/` and `static/` are at the top level.
3. In Render choose **New → Blueprint**, connect the GitHub repository and apply `render.yaml`. This defines a Python service and managed PostgreSQL database. The database and always-on web service may incur charges; check Render's current prices before confirming.
4. In the new web service's Environment settings, set `ADMIN_EMAIL` and Stripe keys. Use test-mode keys only. `LOCALLOOP_SECRET_KEY` is generated by the blueprint.
5. Set up the Stripe webhook endpoint to `https://YOUR-RENDER-SERVICE/stripe/webhook`, select `checkout.session.completed` and `checkout.session.expired`, then paste its signing secret into `STRIPE_WEBHOOK_SECRET`.
6. Deploy and visit `/health`. Register the exact admin email configured in `ADMIN_EMAIL` to create the first admin account. Do this privately before sharing the site.
7. Use Stripe test mode to verify every path. Do not add live keys or announce the marketplace as open until the launch checklist is complete.

If the existing Render service was created with the Docker runtime, don't assume you can switch its runtime in place. Create a new Python service/Blueprint from this repository, test it, and only remove the old service once the new one is verified.
